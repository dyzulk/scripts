Private Container Registry

Push and pull your Docker container images securely. This registry is powered by the OCI Distribution specification.

Registry is Online — API endpoint available at /v2/

Quick Start

1 Login to the registry 
docker login <registry-host>
2 Tag your image 
docker tag <image-name> <registry-host>/<image-name>
3 Push to registry 
docker push <registry-host>/<image-name>
4 Pull from registry 
docker pull <registry-host>/<image-name>

HTTP Configuration

Insecure Registry Note: If this registry is served over plain HTTP, you need to add it to your Docker daemon's insecure-registries list in /etc/docker/daemon.json on the client machine, then restart Docker. 
{
  "insecure-registries": [
    "<registry-host>"
  ]
}

Trust Root CA (Self-Signed / Internal CA)

If your registry is using a Self-Signed/Internal CA certificate, you must trust the Root CA on client machines or within Docker containers to avoid security warnings.

Download Root CA (ca.crt)
1. Configure Docker Daemon (on Client / Dokploy Host)

Run this command to make the Docker daemon trust this registry specifically:

sudo mkdir -p /etc/docker/certs.d/<registry-host> && \
sudo curl -kfsSL https://<registry-host>/ca.crt -o /etc/docker/certs.d/<registry-host>/ca.crt && \
sudo systemctl restart docker
2. Trust CA globally on Client Host (VM / LXC / PC)

If you want other tools (like curl, wget, or local applications) on the host to trust this certificate globally:

# Debian / Ubuntu Host
sudo mkdir -p /usr/local/share/ca-certificates && \
sudo curl -kfsSL https://<registry-host>/ca.crt -o /usr/local/share/ca-certificates/<registry-host>.crt && \
sudo update-ca-certificates
# Alpine Linux (LXC)
apk add --no-cache ca-certificates curl && \
mkdir -p /usr/local/share/ca-certificates && \
curl -kfsSL https://<registry-host>/ca.crt -o /usr/local/share/ca-certificates/<registry-host>.crt && \
update-ca-certificates
3. Trust CA inside Docker Containers

If you have a container running on a client machine that needs to pull/interact with this registry, choose one of these options:

Option A: Mount host's CA (Recommended & Clean)

# Docker CLI mount
docker run -v /etc/ssl/certs:/etc/ssl/certs:ro <image>

# Docker Compose mount
volumes:
  - /etc/ssl/certs:/etc/ssl/certs:ro

Option B: Install CA during Image Build (Dockerfile)

# For Debian/Ubuntu-based images
ADD https://<registry-host>/ca.crt /usr/local/share/ca-certificates/<registry-host>.crt
RUN chmod 644 /usr/local/share/ca-certificates/<registry-host>.crt && update-ca-certificates

# For Alpine-based images
RUN apk add --no-cache ca-certificates
ADD https://<registry-host>/ca.crt /usr/local/share/ca-certificates/<registry-host>.crt
RUN chmod 644 /usr/local/share/ca-certificates/<registry-host>.crt && update-ca-certificates
